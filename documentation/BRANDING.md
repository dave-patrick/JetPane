# Approved branding

- `assets/brand/JetPane-icon.png`: locked folded-plane icon. White and gray wings, purple central fold, black edge definition, three blue control dots along each wing’s trailing edge. Used for the executable/tray via the multi-size ICO.
- `assets/brand/JetPane-wordmark.png`: approved final modern option 5. Uppercase JETPANE, blue JET, silver PANE, integrated overhead flight swoosh ending at the airplane. Purple is confined to the plane fold.
- `assets/design-archive`: retained earlier options. These are explorations, not alternate approved logos.

Raster originals retain their generated transparency. Do not claim the wordmark uses an identified or licensed installable font; it is custom raster lettering. A future vector cleanup should preserve the approved geometry and typography and be reviewed before replacing these originals.

The README and website use the full wordmark. Small app/tray contexts use the standalone icon, never the full wordmark.
