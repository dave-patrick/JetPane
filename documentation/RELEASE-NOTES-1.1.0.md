JetPane is a portable Windows x64 desktop-layout manager with profiles spanning monitors, visual arrangement previews, editable placement locations and custom global shortcuts.

Extract the complete portable ZIP to a writable folder and run JetPane.exe. No installer or separate .NET installation is required. Help.html covers every option. Settings remain beside the executable; login startup is optional and disabled initially.

The release includes the approved airplane icon. This is an early prerelease: 31 local checks and a tray smoke test passed, while physical docking, login startup, real editor gestures and broad application compatibility still need wider validation. One saved profile position per process name. Elevated/system windows have limitations. See README and help for the full boundaries.

Attached SHA256SUMS.txt verifies download integrity. Binaries are currently unsigned. The full source, website, screenshots, documentation and design history are in the repository under the existing MIT license.
