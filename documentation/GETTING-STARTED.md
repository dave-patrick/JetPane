# Getting started

1. Download the portable ZIP from [Releases](https://github.com/dave-patrick/JetPane/releases).
2. Extract all files to a writable directory. Keep Help.html next to JetPane.exe.
3. Run JetPane.exe. On first launch you can save your current arrangement to Default.
4. Right-click the tray icon for commands. Double-click for Settings.
5. Save with Ctrl+Alt+S; restore with Ctrl+Alt+R; preview with Ctrl+Alt+P.

## Profiles across monitors

Arrange your apps, create a named profile, and save it. Assign the current profile to the connected monitor configuration if you want automatic docking layouts. Repeat for your other configuration. Profiles store monitor geometry for previews; old profiles use current geometry until saved again.

## Visual locations

Open Locations → Create / edit locations. Create a named rectangle by dragging outside the current region. Drag inside to move it; drag a handle to resize. Numeric fields provide exact coordinates. Save, then assign its combination in Keyboard shortcuts. Activate an app and press the combination.

## Keyboard configuration

Enter combinations like Ctrl+Shift+F8. Leave a cell empty to disable an action. Save shortcuts to apply. If Windows has reserved a key, change it after checking registration status. The tray’s Disable Global Hotkeys turns off all shortcuts without deleting them.

## Upgrade

Exit the old copy first, preserve/export settings, then replace the application files. Settings stay beside the executable. If moving the folder, disable the old startup entry before moving and re-enable from the new location. WindowPilot schema-1 settings and .wpilot exports remain supported.

Read [complete help](../docs/help.html) for every command and limitation.
