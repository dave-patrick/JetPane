# JetPane

User-approved product: a self-contained portable Windows x64 application with no installer. Save and preview multi-monitor arrangements; visually draw/edit named locations and move active windows using configurable shortcuts. Retain the published feature behavior described in the repository help, while documenting implementation limits honestly.

Brand decisions approved in this conversation: JetPane name; folded paper-plane icon with three control dots along each wing’s trailing edge; uppercase modern wordmark, blue JET and silver PANE, with an integrated overhead swoosh and plane. Purple belongs to the plane fold, not the lettering.

The landing page introduces the actual utility, demonstrates the three placement modes and leads to the portable release, help and source. No fabricated testimonials, metrics or compatibility claims. Screenshots use labeled synthetic sample layouts. No account, telemetry or remote configuration.
