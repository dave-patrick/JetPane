Choose the tool for the job.

Atomic 22 Industries publishes a collection of independent tools. The directory connects each project to its own explanation, setup guide and actual available download.

  1. Desktop and workspace

    JetPane arranges Windows applications across monitors. arnés brings separately running dashboards and service information into a local browser workspace.

  2. Reading and video

    Yomu collects reading material and supports listening on Android. motus.leap helps organise a YouTube library through a configured backend and Android companion.

  3. Planned and archived work

    Quantos is a planned linked-Markdown workspace. JobSaver and the earlier YouTube playlist agent remain archived source projects; the archive links preserve their history.

Downloads are project-specific

Portable executables, Android development APKs, source packages and planned projects are different states. Every app page identifies its requirements and availability so you can choose the right starting point.
